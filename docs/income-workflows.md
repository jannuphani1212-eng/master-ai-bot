# Five specialist income workflows

These workflows are planning aids, not promises of earnings. The agents must distinguish verified facts from assumptions and must not invent live prices, commissions, platform approvals, traffic, or revenue.

## 1. Affiliate Marketing

1. Choose one narrow audience and product category.
2. List candidate products and the platform where each can legally be promoted.
3. Verify current product availability, affiliate-program eligibility, commission rate, cookie rules, and disclosure requirements from official sources before recommending a product.
4. Compare product usefulness, buyer intent, competition, and content potential.
5. Prepare original Telugu and/or English comparison content, short-video scripts, and a publishing calendar.
6. Add a clear affiliate disclosure and submit each asset for human review.
7. Track clicks, click-through rate, conversion rate, returns, and net commission. Stop promoting products with poor user value or negative economics.

## 2. YouTube

1. Define the channel audience, language, format, and repeatable content promise.
2. Research topics and competing videos without copying scripts, visuals, music, or branding.
3. Create an original hook, script, scene plan, title, description, and thumbnail brief.
4. Check music, footage, image, voice, child-safety, and platform-policy rights.
5. Prepare a draft package for human approval before upload.
6. After publishing, review impressions, click-through rate, average view duration, retention, returning viewers, and subscriber conversion.
7. Improve one variable at a time. Do not promise views, monetisation approval, or income.

## 3. Blogging

1. Select a specific audience problem and validate search intent.
2. Build a keyword cluster and article outline.
3. Draft original content that answers the query better than a generic summary.
4. Mark claims, prices, statistics, and citations that need fact-checking; never fabricate sources.
5. Prepare title, meta description, headings, internal links, image alt text, and a useful next step.
6. Run editorial, copyright, and factual checks; publish only after human approval.
7. Track indexed pages, impressions, clicks, rankings, engagement, and qualified leads or affiliate conversions.

## 4. App Development

1. Identify a real user problem and interview or otherwise validate the intended users.
2. Write a small MVP specification, user stories, acceptance criteria, and a no-cost-first technology plan.
3. Estimate development time, hosting, API usage, maintenance, privacy, and security requirements.
4. Generate complete files and explain setup steps for the target device and skill level.
5. Test the main user flows, errors, accessibility, data handling, and security before release.
6. Prepare release notes and a rollback plan; deployment requires human approval.
7. Measure active users, task completion, retention, support burden, and operating cost before choosing monetisation.

## 5. SEO

1. Record the current site structure, indexation, performance, and search visibility.
2. Map search intent to pages and build a prioritised keyword cluster.
3. Fix crawlability, indexation, mobile usability, page speed, metadata, headings, and internal links.
4. Improve content usefulness and factual accuracy; do not keyword-stuff or create doorway pages.
5. Prepare changes and an implementation checklist for review.
6. After approval and release, monitor Search Console impressions, clicks, CTR, indexed pages, conversions, and technical errors.
7. Never guarantee rankings or invent search-volume data.

## Shared rules

- Start with free or low-cost actions when the user's budget is limited.
- Show assumptions, dependencies, risks, estimated costs, and measurable next steps.
- Never claim a campaign, app, article, video, or website has been published or deployed unless that action actually happened.
- Require explicit human approval before publishing, sending, purchasing, spending, deleting, changing account settings, or deploying.
- Protect API keys and personal information. Do not put secrets in prompts, logs, or frontend code.
- Measure net results after fees, refunds, taxes, and operating costs. Earnings are not guaranteed.
